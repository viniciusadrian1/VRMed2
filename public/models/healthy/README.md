# Modelos saudáveis (.glb)

Coloque aqui os arquivos `.glb` dos órgãos em estado saudável.

- O nome do arquivo deve corresponder ao `id` do órgão no catálogo
  (`lib/organs.ts`). Exemplo: `coracao.glb`, `pulmao.glb`, `figado.glb`.
- Enquanto o arquivo não existir, o visualizador exibe um modelo de
  demonstração procedural — a aplicação continua totalmente funcional.
- Para melhor desempenho das camadas e do raio-X, nomeie os meshes do modelo
  de forma descritiva (ex.: `skin`, `muscle`, `vessel`, `bone`).
